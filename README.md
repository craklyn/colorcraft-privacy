# Sketchino — privacy policy

The published privacy policy for **Sketchino** (formerly ColorCraft Young Artist), served at
https://craklyn.github.io/colorcraft-privacy/

`index.html` is **generated**. The source of truth is `docs/privacy_policy.md`
in the app repository, rendered by `build_privacy_page.py`. Editing this file by
hand would make the published page disagree with the document it claims to
describe, which for a privacy policy is the one thing that must never happen.

To update: change the markdown in the app repo, regenerate, and copy the HTML
here.
